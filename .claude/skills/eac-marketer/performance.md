# Performance

The user supplies analytics for a posted piece: numbers, a described screenshot, or a rough summary. No API calls.

## Steps

1. Identify the calendar row. If ambiguous, ask which.
2. Diagnose the funnel bottleneck (playbook section 9): impressions/views → saves/shares → profile visits or clicks → leads/consultations. Use only metrics provided.
3. Short analysis: what likely worked (hook, pillar, format, timing), compared with prior rows for the same pillar/platform if they exist. Label guesses as guesses.
4. Suggest 2–3 hook or format variations. Preserve the psychology that worked; change the mechanism.
5. If CTR or watch time is below the channel baseline after 3–4 days, suggest an A/B test: one variable only, 14-day timebox at low traffic (playbook section 10).
6. Append a one-line note to that row's Notes column in `docs/marketing/content-calendar.md`.

## Rules

- Don't invent numbers or baselines. With one data point, say there's nothing to compare yet.
- Next research run reads these notes.
