# Content engine

Before proposing a topic, check `docs/marketing/youtube-catalog.md` so you don't repeat a posted one.

Drafts text from footage notes, a transcript, or raw interview answers (pasted or described; no video processing).

**Read first:** `docs/marketing/references/youtube-engine-playbook.md` and `docs/marketing/content-grader.md`.

## Pick what to build

1. Read `docs/marketing/idea-inbox.md`. Build inbox ideas first.
2. If a brand-voice conflict exists in an inbox idea, don't drop it. Flag the conflict and offer a compliant rewrite.
3. With no inbox ideas, use the latest `docs/marketing/trend-briefs/` file from the last 7 days as inspiration, same tier as your own ideas.

## Outputs

| Output | Notes |
|--------|-------|
| Long-form script structure | Narrative beats, not word-for-word. Hook follows promise (0–15s), proof (15–30s), plan (30–60s) |
| Short-form cutdowns | Instagram and YouTube Shorts: hook line, beats, caption, CTA |
| Thumbnail concepts | Text only: subject, contrast text block, before/after element, single promise matching the title |
| Title options | Outcome-first, specific, no hype |
| Description + chapters | Keyword-dense, derived from the script (playbook section 4) |
| CTA | Logical next step of what the piece taught, e.g. tint comparison tool or consultation |
| Build Archive copy | Specs, difficulties, owner story, in the site's voice → `docs/marketing/build-archives/<car-slug>-archive.md` |

## Grade every piece

Score with the rubric before showing anything.

- 28–35 PUSH: show as-is.
- 20–27 REVISE: rewrite the weak part (usually the hook), re-grade, show only the revision.
- Below 20 REWRITE: redraft, re-grade, show only the rewrite.

Show the final score and one line on why. Don't rubber-stamp: if everything scores PUSH, the grading is wrong.

## Stage, don't approve

Save drafts, set the calendar row to `drafted`, and add an unchecked line to `docs/marketing/approval-queue.md`. Never check it yourself.

## Rules

- Never invent specs, quotes, or results. Use `TBD` and list what's missing.
- Tag each piece with one pillar.
