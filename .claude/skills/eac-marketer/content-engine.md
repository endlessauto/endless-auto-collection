# Content engine

Before proposing a topic, check `docs/marketing/youtube-catalog.md` so you don't repeat a posted one.

Drafts text from footage notes, a transcript, or raw interview answers (pasted or described; no video processing).

**Read first:** `docs/marketing/references/writing-style.md` (banned words, openers, self-check; run it on every draft), `docs/marketing/references/youtube-engine-playbook.md`, `docs/marketing/references/kallaway-short-form-playbook.md` (sections 4–6), and `docs/marketing/content-grader.md`.

## Pick what to build

1. Read `docs/marketing/idea-inbox.md`. Build inbox ideas first.
2. If a brand-voice conflict exists in an inbox idea, don't drop it. Flag the conflict and offer a compliant rewrite.
3. With no inbox ideas, use the latest `docs/marketing/trend-briefs/` file from the last 7 days as inspiration, same tier as your own ideas.

## Outputs

| Output | Notes |
|--------|-------|
| Long-form script structure | Narrative beats, not word-for-word. Hook follows promise (0–15s), proof (15–30s), plan (30–60s) |
| Short-form cutdowns | Instagram and YouTube Shorts: hook (text, visual, spoken, drafted in that order), beats, caption, CTA |
| Thumbnail concepts | Text only: subject, contrast text block, before/after element, single promise matching the title. Each must evoke one clear emotion through a visible face, reaction or stake |
| Title options | Outcome-first, specific, no hype, and each carries one clear emotion (relief, tension, pride, curiosity) |
| Description + chapters | Keyword-dense, derived from the script (playbook section 4) |
| CTA | Logical next step of what the piece taught, e.g. tint comparison tool or consultation |
| Lead-magnet funnel copy | When asked: comment keyword (hyper-specific), auto-DM text, landing page (outcome headline, specific subheadline, 3 bullets, one field, "Send me the [thing]"), delivery line. Playbook section 5 |
| Build Archive copy | Specs, difficulties, owner story, in the site's voice → `docs/marketing/build-archives/<car-slug>-archive.md` |

## Short-form hook rules

- Write the text hook first, then the visual, then the spoken line. All three must say the same thing (max alignment). Show them as three labeled lines.
- First sentence: on-target clarity (what this is, who it's for), about 5th-grade reading level.
- Include a curiosity loop: viewer's current belief vs. the true, backable contrast. Never manufacture a gap.
- When remixing an outlier, keep 8–10 bricks (format, hook structure, script structure, visuals) and change 1–3. Cite the source outlier link. Never copy word for word.
- Aim the piece at likely customers, not max reach. End on a next step that fits what was taught.
- Match content <> audience <> lead magnet: the CTA asset must relate to what the video covered. Name the asset and mark it `exists`, `TBD`, or `needs building`. Never imply a ManyChat flow, email list, or landing page is live unless the user confirms.
- Sprint mode ("first 3 videos"): for each of 3 outliers from 3 formats, output the hook breakdown (text, visual, spoken), the beat-by-beat structure, the held bricks vs. the changed brick, and a script in our words and real facts. Recording and editing happen off-system.

## Grade every piece

Score with the rubric before showing anything.

- 32–40 PUSH: show as-is.
- 23–31 REVISE: rewrite the weak part (usually the hook), re-grade, show only the revision.
- Below 23 REWRITE: redraft, re-grade, show only the rewrite.

Show the final score and one line on why. Don't rubber-stamp: if everything scores PUSH, the grading is wrong.

## Stage, don't approve

Save drafts, set the calendar row to `drafted`, and add an unchecked line to `docs/marketing/approval-queue.md`. Never check it yourself.

## Rules

- Never invent specs, quotes, or results. Use `TBD` and list what's missing.
- Tag each piece with one pillar.
